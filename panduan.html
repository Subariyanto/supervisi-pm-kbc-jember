1. Pendahuluan

Aplikasi Supervisi PM-KBC adalah aplikasi berbasis web yang dirancang untuk membantu Pengawas Madrasah dalam melaksanakan supervisi pembelajaran, kokurikuler, ekstrakurikuler, dan iklim madrasah sesuai dengan standar Pokjawas Jawa Timur.

Fitur Utama

  • Input supervisi pembelajaran per guru dengan penilaian skor 1-4
  • Input supervisi kokurikuler, ekstrakurikuler, dan iklim madrasah per madrasah
  • Cetak instrumen supervisi dan rekap hasil
  • Cetak laporan lengkap (cover, kata pengantar, BAB I-V, lampiran)
  • Laporan per madrasah dan per KKMA
  • Backup dan restore data
  • Multi-user dengan sistem login
Catatan: Semua data tersimpan di localStorage browser. Artinya data hanya tersedia di browser dan perangkat yang sama. Gunakan fitur Backup secara berkala untuk mengamankan data Anda.

2. Login dan Registrasi

Login

Langkah 1: Buka aplikasi di browser Anda.
Langkah 2: Masukkan username dan password.
Langkah 3: Klik tombol Login.

Akun Default

UsernamePassword
adminadmin123
Penting: Segera ubah password default setelah login pertama kali melalui menu Ubah Password.

Registrasi Akun Baru

Langkah 1: Di halaman login, klik link Daftar.
Langkah 2: Isi nama lengkap, username (min. 3 karakter), dan password (min. 4 karakter).
Langkah 3: Konfirmasi password, lalu klik Daftar.
Langkah 4: Setelah berhasil, Anda akan diarahkan ke halaman login.

3. Dashboard

Dashboard menampilkan ringkasan data supervisi Anda:

  • Total Supervisi - Jumlah supervisi pembelajaran yang telah dilakukan
  • Data Madrasah - Jumlah madrasah yang terdaftar
  • Data Guru - Jumlah guru yang terdaftar

Di bawah statistik terdapat Daftar Supervisi yang menampilkan semua data supervisi pembelajaran beserta persentase capaian. Anda dapat:

  • Klik item untuk melihat detail
  • Klik ikon pensil untuk mengedit
  • Klik ikon hapus untuk menghapus data

Grafik capaian ditampilkan di bagian bawah untuk visualisasi perbandingan skor Perencanaan, Pelaksanaan, dan Asesmen.

4. Data Pengawas

Menu ini digunakan untuk mengisi identitas pengawas yang akan tampil di laporan.

Langkah 1: Klik menu Data Pengawas di sidebar.
Langkah 2: Isi data: Nama Pengawas, NIP, Pangkat/Golongan, dan informasi lainnya.
Langkah 3: Klik Simpan.
Catatan: Data pengawas akan otomatis muncul di semua laporan yang dicetak.

5. Data Madrasah

Kelola daftar madrasah binaan Anda di menu ini.

Tambah Madrasah

Langkah 1: Klik menu Data Madrasah di sidebar.
Langkah 2: Klik tombol + Tambah Madrasah.
Langkah 3: Isi data: Nama Madrasah, NPSN, Alamat, Kabupaten/Kota, Kepala Madrasah.
Langkah 4: Klik Simpan.

Import dari Excel

Langkah 1: Klik tombol Template Excel untuk mengunduh template.
Langkah 2: Isi data madrasah di file Excel sesuai format template.
Langkah 3: Klik tombol Import Excel dan pilih file yang sudah diisi.

6. Data Guru

Kelola daftar guru yang akan disupervisi.

Tambah Guru

Langkah 1: Klik menu Data Guru di sidebar.
Langkah 2: Klik tombol + Tambah Guru.
Langkah 3: Isi data: Nama Guru, NIP, Madrasah, Mata Pelajaran, dan Kelas.
Langkah 4: Klik Simpan.

Import dari Excel

Sama seperti data madrasah, Anda dapat mengunduh template dan mengimport data guru dari file Excel.

7. Supervisi Pembelajaran

Fitur utama untuk melakukan supervisi pembelajaran per guru. Terdiri dari 3 komponen penilaian:

KomponenJumlah IndikatorKeterangan
Perencanaan10Telaah dokumen RPP/Modul Ajar
Pelaksanaan10Observasi pembelajaran di kelas
Asesmen8Penilaian dan evaluasi pembelajaran

Input Supervisi Baru

Langkah 1: Klik menu Supervisi Pembelajaran > Input Supervisi.
Langkah 2: Isi identitas: pilih guru, tanggal supervisi, materi, dll.
Langkah 3: Klik Lanjut untuk masuk ke penilaian Perencanaan.
Langkah 4: Beri skor 1-4 untuk setiap indikator perencanaan. Klik aspek (teks biru bergaris) untuk melihat penggalian data.
Langkah 5: Lanjut ke Pelaksanaan, beri skor 1-4 untuk setiap indikator.
Langkah 6: Lanjut ke Asesmen, beri skor 1-4 untuk setiap indikator.
Langkah 7: Klik Simpan untuk menyimpan hasil supervisi.

Rekap Hasil

Menu Supervisi Pembelajaran > Rekap Hasil menampilkan tabel rekap seluruh supervisi yang telah dilakukan, lengkap dengan skor per komponen dan predikat akhir.

Cetak Hasil

Menu Supervisi Pembelajaran > Cetak Hasil memungkinkan Anda mencetak instrumen supervisi per guru dalam format yang siap print.

8. Supervisi Kokurikuler

11. Cetak Laporan Lengkap

Setiap jenis supervisi memiliki fitur cetak laporan lengkap yang menghasilkan dokumen resmi dengan struktur:

  • Cover/Halaman Judul - Judul laporan, nama pengawas, instansi
  • Kata Pengantar - Pengantar laporan supervisi
  • BAB I - Pendahuluan - Latar belakang, tujuan, sasaran
  • BAB II - Landasan Hukum - Dasar hukum pelaksanaan supervisi
  • BAB III - Pelaksanaan - Waktu, tempat, metode supervisi
  • BAB IV - Hasil - Data hasil supervisi dan analisis
  • BAB V - Penutup - Kesimpulan dan rekomendasi
  • Lampiran - Instrumen dan data pendukung
Cara Cetak:
1. Buka menu Cetak Laporan Lengkap pada jenis supervisi yang diinginkan.
2. Pastikan data pengawas dan data supervisi sudah terisi.
3. Klik tombol Cetak Laporan.
4. Gunakan Ctrl+P atau tombol Print untuk mencetak/menyimpan sebagai PDF.

12. Laporan Per Madrasah

Fitur ini tersedia untuk supervisi Kokurikuler, Ekstrakurikuler, dan Iklim Madrasah. Memungkinkan Anda mencetak laporan khusus untuk satu madrasah tertentu.

Langkah 1: Buka menu Laporan Per Madrasah pada jenis supervisi yang diinginkan.
Langkah 2: Pilih madrasah dari daftar dropdown.
Langkah 3: Klik Cetak atau gunakan Ctrl+P.

14. Export/Backup dan Restore

Fitur ini sangat penting untuk mengamankan data Anda karena semua data tersimpan di browser (localStorage).

Backup Data

Langkah 1: Klik menu Export/Backup & Restore di sidebar.
Langkah 2: Klik tombol Backup/Export Data.
Langkah 3: File JSON akan terunduh otomatis. Simpan file ini di tempat yang aman.

Restore Data

Langkah 1: Klik menu Export/Backup & Restore di sidebar.
Langkah 2: Klik tombol Restore/Import Data.
Langkah 3: Pilih file backup JSON yang pernah Anda simpan.
Langkah 4: Konfirmasi restore. Data lama akan ditimpa dengan data dari file backup.
Perhatian: Restore akan menimpa SEMUA data yang ada saat ini. Pastikan Anda membackup data terbaru sebelum melakukan restore.

15. Tips dan Catatan Penting

Penyimpanan Data

  • Data tersimpan di localStorage browser, bukan di server
  • Jika Anda menghapus data browser/cache, data supervisi akan hilang
  • Data hanya bisa diakses dari browser dan perangkat yang sama
  • Lakukan backup rutin (minimal seminggu sekali)

Kompatibilitas Browser

  • Gunakan browser modern: Chrome, Edge, Firefox, atau Safari versi terbaru
  • Pastikan JavaScript diaktifkan
  • Aplikasi responsif dan bisa diakses dari HP/tablet

Tips Penggunaan

  • Isi data pengawas dan data madrasah terlebih dahulu sebelum melakukan supervisi
  • Gunakan fitur import Excel untuk input data madrasah dan guru dalam jumlah banyak
  • Klik teks indikator (berwarna biru) untuk melihat panduan penggalian data
  • Gunakan tombol Reset Skor jika ingin mengulang penilaian dari awal
  • Untuk mencetak, gunakan Ctrl+P dan pilih "Save as PDF" jika ingin menyimpan digital
  • Indikator dapat diedit/disesuaikan melalui panel Edit Indikator di halaman input supervisi
